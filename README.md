# .github

The public organisation profile for **Colouring Code**, shown at
[github.com/colouringcode](https://github.com/colouringcode).

- `profile/README.md` — the profile page itself.
- `profile/assets/` — the SVG artwork it renders (banners, discipline strip
  and the petal rule), built from the studio's brand tokens.

The artwork is hand-written SVG with no external fonts or requests: the type
falls back through `Archivo Black` → `Arial Black` and `Space Grotesk` →
`Helvetica`, because GitHub serves images through its own image proxy.

Colours are the site's own — `--cc-forge` `#FF5B14`, `--cc-rose-amber`
`#FFB000`, `--cc-rose-teal` `#12A39A`, `--cc-rose-cobalt` `#2747C9`,
`--cc-rose-magenta` `#E5267A` on `--cc-surface` `#F6F1E7` and `--cc-ink`
`#141414`.
