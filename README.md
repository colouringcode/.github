# .github

The public organisation profile for **Colouring Code**, shown at
[github.com/colouringcode](https://github.com/colouringcode).

- `profile/README.md` — the profile page itself.
- `profile/assets/` — the SVG artwork it renders, built from the studio's brand
  tokens: a desktop banner and a phone banner (light and dark), the discipline
  strip in wide and stacked forms, and the petal rule.

The artwork is hand-written SVG with no external requests. GitHub serves images
through its own proxy, so type falls back through `Space Grotesk` → `Helvetica`;
the wordmark is set 700/400 in that family, as it is on the site, rather than in
Archivo Black.

Colours are the site's own — `--cc-forge` `#FF5B14`, `--cc-rose-amber`
`#FFB000`, `--cc-rose-teal` `#12A39A`, `--cc-rose-cobalt` `#2747C9`,
`--cc-rose-magenta` `#E5267A` on `--cc-surface` `#F6F1E7` and `--cc-ink`
`#141414`. The strapline "Straight talking. Full colour." carries the petal
gradient on "Full colour.", as it does on the site and the invoice.
